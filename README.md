This program forecasts every GTA VI trophy's Exophase earn rate at 2026-11-26 00:00 UTC as five quantiles per trophy, from the house's recorded reads up to the deadline. It models earner counts versus players tracked with Exophase refresh/dilution modelling and logit-normal spreads, scored by mean pinball loss on the logit scale.

## Run it

```sh
MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out python3 main.py
```
